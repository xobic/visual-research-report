# Changelog

## 0.5.0

- Added the `editorial-dashboard` preset: a compact sticky chapter track, 25–32% desktop evidence rail, and chapter-synchronized dashboard states.
- Added optional section dashboard contracts for one primary fact, a unit-consistent evidence trend, two-to-four chapter metrics, and one-to-three probability paths.
- Reworked chapter rhythm so the first argument block and evidence chart share the opener viewport instead of leaving a title-only screen.
- Added deterministic and browser QA for dashboard geometry, scroll synchronization, responsive collapse, fact-backed controls, and first-evidence placement.
- Kept the Image 2 four-state theme-atom cover contract unchanged and fully compatible.

## 0.4.0

- Added the `editorial-scrollspy` preset, combining longform editorial measures with a sticky segmented chapter track.
- Added fact-validated `history-scrolly` charts with ordered focus scenes and reduced-motion/print fallbacks.
- Added `causal-horizon-map` charts with fact-bound signals, lags, thresholds, confidence, direction, sparklines and directed edges.
- Added declarative theme-atom engineering schematics so one physical object can drive recursive, exploded, blueprint and impact cover states without raster artwork.
- Added an Image 2-first theme-atom production path: freeze one canonical identity anchor, derive all four cover states directly from it, record generation provenance, and reject missing or inconsistent production assets instead of silently degrading.
- Extended browser and package QA for scroll scenes, causal-node semantics, engineering cover parts and responsive sticky navigation.

## 0.3.0

- Added the reference-faithful `editorial-longform` design preset alongside `institutional-rail`.
- Added structured evidence status, reference contracts, chart/fact consistency checks, and explicit synthetic disclosure rules.
- Added tension-balance/tripwire visualization support and stricter matrix, probability, paired-comparison, scale, and precision validation.
- Strengthened single-file offline verification, inline JavaScript parsing, manifest finalization, responsive interaction QA, and print/PDF export.
- Made Figma optional; local assets, image generation, and engineering schematics remain supported fallbacks.
